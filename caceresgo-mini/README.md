# CaceresGo Mini 🗺️
Mini juego inspirado en mi TFG: recorre la ciudad monumental de Cáceres y descubre monumentos.

- **Controles:** flechas / WASD, o toca el mapa.
- **Puntos:** cada monumento da puntos y hay bonus por racha.
- **Récord:** se guarda con `localStorage`.
- **Sin dependencias:** solo abre `index.html`.

**Conceptos:** SVG dinámico, eventos de teclado y puntero, `<dialog>`, animaciones CSS, `localStorage`.
